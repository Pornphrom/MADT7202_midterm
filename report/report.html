Which note should ScentSelf anchor its debut perfume on?

MADT 7202 Mid-Term · Palaloy · Code & notebook: @@REPO@@

1 The decision

Palaloy, as ScentSelf founder, picks up to 3 anchor notes for the debut concept before the next IS tester round. A note qualifies only if it is a stable bridge more central than its popularity predicts; if none passes, Lemon is kept only as the control anchor, not as the positioning claim.

2 Why a network

A frequency table shows which notes are common, not which sit between separate note groups. “Bridge vs. merely popular” is a question about paths: it needs the co-occurrence graph (betweenness vs. frequency rank).

4 Graph construction

NodeCleaned fragrance note
EdgeTwo notes listed in the same perfume
WeightPerfumes sharing the pair (raw count); NPMI as check
PruningDrop generic notes in ≥20% of perfumes (10, e.g. Bergamot, Vetiver, Cedar) before ranking; keep notes in ≥5 perfumes (89) and edges ≥6 perfumes (set by a fixed density rule, 0.12)
Final20 nodes, 23 edges (13-note core + 3 small clusters)

5 The picture

Node size = betweenness; colour = note’s dominant scent family; line width = perfumes sharing the pair.

6 Findings

  • Bridges are popular notes. Top 5 by betweenness — Lemon, Mandarin Orange, Tonka Bean, Orange Blossom, Oakmoss — rank 1, 2, 3, 7, 6 by frequency (Spearman 0.66, n=20). No note passes the preset rule (≥5 ranks better than frequency and top 10 in ≥80% of brand-cluster bootstrap runs).
  • The one exception is unstable. Peach beats its frequency rank by 10 places (6th vs 16th) but is top 10 in only 24% of 300 resamples (Lemon 87%). The other 13 notes have zero betweenness: they are not bridges.
  • Same verdict elsewhere: no pass on all 1,780 perfumes (Cedar, Orange Blossom 100% but gap ≤1); all 7 bridges survive NPMI weighting.

7 Recommended action

  • Step 1 (before testers): fix Lemon as the control anchor (stable bridge, 87%).
  • Step 2 (before testers): brief 2 prototypes — Lemon alone; Lemon + Peach (the only bridge beating popularity; unstable).
  • Step 3 (tester round): IS testers compare them; keep Peach only if it beats the Lemon control, else go with Lemon.

8 What would change my mind

A non-generic note in the top 10 in ≥80% of resamples with a ≥5-rank gap on a larger catalogue. Sensitive to the cutoff (at 8, only Lemon has betweenness >0) and generic cut (at 25%, Cedar and Vetiver return as top bridges, gap 0). Families uneven (Floral 61, Leather 4).
